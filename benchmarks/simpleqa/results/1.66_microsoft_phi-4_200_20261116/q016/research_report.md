# Research report

**Objective:** For the original Groove Coaster game for iOS, all the original songs were by Hirokazu Koshio (COSIO) and whom?

**Status:** finished by the agent on turn 13

## Final result

For the original Groove Coaster game for iOS, all the original songs were by Hirokazu Koshio (COSIO) and Shohei Tsuchiya. This information is supported by discovery [1].

## Discoveries (2)

### 1. Turn 8, from https://groovecoaster.fandom.com/wiki/Groove_Coaster_(iOS)

The original songs for the iOS version of Groove Coaster were composed by Hirokazu Koshio (COSIO) and Shohei Tsuchiya. Specific songs by COSIO include 'The Beginning', 'Music Plot Type Zero', 'Happy Smiling ♪ -More Happy Mix-', 'Invade You', 'Neptune Diving', 'You've Gatta Luv', 'I CANNOT APE', 'Fun-House', '檄', 'Cardiac Rhythm', 'Spring to mind', 'Eurythmics Trip', 'Protocol Signal Generation', 'Space Invaders Infinity Gene Medley', and 'Just no friend'. Songs by Shohei Tsuchiya include 'Play merrily', 'Streetwalker', 'Not get wish', 'Breach of faith', 'You've Gatta Luv', 'Spring to mind', 'Good-bye my earth', and 'Hello 31337'.

### 2. Turn 10, from https://groovecoaster.fandom.com/wiki/Groove_Coaster_(iOS)

Version 2.0 Update includes the following default songs: 'Fess Up!' by Shohei Tsuchiya and 'Thrash Beat' by COSIO.
